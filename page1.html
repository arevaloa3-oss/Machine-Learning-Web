Machine learning works by training computers using large amounts of data so they can recognize patterns and make predictions over time.

Supervised Learning

This type uses labeled data where the correct answers are already known. The system learns by comparing its output to the correct answer and improving over time.

Unsupervised Learning

This type works with data that has no labels. The system finds patterns and groups on its own without being told what to look for.

Reinforcement Learning

This type learns through trial and error. The system gets rewards for correct actions and penalties for incorrect ones, helping it improve over time.
